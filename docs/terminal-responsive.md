# Адаптация терминала

До 700 px: список заказов → чек → отдельный каталог с категориями → оплата. Возврат к списку сохраняет текущий черновик. Чек на всю ширину, прокрутка содержимого отдельно от кнопки оплаты. Дополнительные действия и комментарий доступны через «⋯». Оплата использует клавиатуру устройства. Поставка оформлена карточками с подписью количества и цены. Архив показывает список над деталями.

От 701 px: каталог и чек в соседних панелях, экранная цифровая клавиатура оплаты. Дополнительные правила для низких экранов в альбомной ориентации.

Проверка `tests/responsive-pos-smoke.html`: каталог/чек, оплата, поставка, архив, передача, PIN, приёмка, смена производства. Размеры 320×568, 390×844, 768×1024, 1024×768, 844×390, 1440×900. Проверяется горизонтальное переполнение полей и доступность оплаты на телефоне. 48 проверок прошли в Chrome headless. Функциональные проверки `tests/pos-ui-smoke.html`: 115 прошли.

Визуальный мобильный предпросмотр: `tests/mobile-preview.html?screen=checkout` (также catalog, supply, archive, production, pin, receiving, kitchen-shift). Тестовые страницы используют имитацию API и не включаются в Render-образ.

Это не проверка физических устройств. Перед эксплуатацией проверить Safari iOS и Chrome Android с системной клавиатурой, поворотом экрана и длинным чеком. Принтеры в эту работу не входят.
