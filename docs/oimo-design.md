# Визуальная система Oimo

Основной цвет — сливовый `#633d60`, фон — тёплый `#faf8f5`, акцент — абрикосовый `#f3bc97`. Зелёный и красный сохраняют смысл статусов и ошибок. Общие правила находятся в `oimo.css`, подключённом после модульных стилей на всех четырёх страницах. Правила ограничены экраном и не меняют печатные документы.

Админка: отдельная тёмная навигация, светлая рабочая область, белые таблицы с тонкими разделителями, сгруппированные фильтры. Терминал: светлая панель действий, выделенный чек, компактные категории с количеством доступных позиций, отдельная прокрутка чека и постоянная кнопка оплаты. Оплата: одинаковая иерархия способов оплаты, заметное активное поле, крупная цифровая клавиатура. Суммы и количества используют табличные цифры.

Основные зоны нажатия кассы — 40–56 px, явный фокус клавиатуры, поддержка reduced motion. Категории считают только позиции, доступные по действующим правилам раздачи. Редизайн не меняет роли, расчёты, API и правила движения остатков.

Основания для UX:
- https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum/
- https://www.w3.org/WAI/WCAG22/Understanding/focus-appearance/
- https://www.nngroup.com/articles/progressive-disclosure/

Проверены браузерные сценарии POS, админки и учёта. Визуально просмотрены главная, склад, каталог, оплата; компактная касса проверяется при 1024×768. Это не заключение о полном соответствии WCAG и не замена тестирования с кассирами.
